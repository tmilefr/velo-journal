Depuis le guidon

Publier une étape prend deux minutes, sous la pluie

La page de saisie est faite pour un téléphone tenu d'une main : le mot de passe est retenu trente jours, la position se prend d'un bouton, les photos partent en lot.

  • Titre, récit, photos. Jusqu'à dix médias par étape, redimensionnés à l'arrivée. Une photo mise en avant, une sélection pour le livre.
  • La trace fait le calcul. Déposez le GPX : distance, dénivelé et point d'arrivée en sont déduits, ainsi que les pays et régions traversés — au prorata quand l'étape passe une frontière.
  • Les jours sans vélo comptent aussi. Repos, étape à cheval sur deux journées, transfert en train : chacun est rangé à sa place et n'abîme pas les moyennes.
  • Ce qui reste privé le reste. Une étape peut n'être visible que de vous, et chaque étape porte une note d'intendance que personne d'autre ne lit.

Ce que la trace raconte

Les chiffres du voyage, sans tableur

Deux pages réservées à l'administrateur. L'une compte les kilomètres, l'autre les euros — et aucune des deux ne demande de saisir quoi que ce soit en double.

  • Distances. Jours roulés et jours de repos, moyennes, records, distance mois par mois, et le trajet total vélo + train.
  • Par pays et par région. Neuf régions dans cinq pays sur le voyage de démonstration, cinq étapes à cheval sur une frontière comptées des deux côtés.
  • Finances. Restaurant, hébergement (hôtel ou camping), nourriture, divers ; réparti par personne ; mois par mois. Les achats de préparation entrent dans le budget, pas dans les kilomètres.

Ceux qui suivent

Commentaires

Un mot de Mamie, chaque soir

Prénom et message, avec des réponses en fil. Une page rassemble tout le carnet, filtrable par personne — et le lien du filtre se partage tel quel.

Abonnements

Un e-mail à chaque étape

Inscription à double confirmation, désabonnement en un clic, validation à la main si le courriel se perd. De votre côté, une alerte dès qu'un commentaire arrive.

Flux RSS

Pour les lecteurs équipés

Le carnet publie un flux : ceux qui vivent dans Feedly ou NetNewsWire n'ont rien à changer à leurs habitudes.

Après le retour

Le voyage sort de l'écran

Trois pièces imprimables, dessinées par le carnet à partir de vos propres étapes : une affiche à encadrer, un livre à relier, un diplôme à offrir. Aperçu, impression et export PNG sont la même image, dessinée sur un canvas.

  • L'affiche A3. Les traces sur un fond épuré ou les tuiles OpenStreetMap, la photo favorite de chaque étape posée au plus près de son point d'arrivée, reliée par un fil.
  • Le livre photo. Une page A4 par étape : titre, chiffres du jour, récit et collage. Chaque photo garde sa forme, rien n'est rogné. La carte fait la couverture, le profil la quatrième.
  • Le diplôme. Pour le compagnon de route monté en selle en chemin : ses kilomètres à lui, comptés depuis sa première étape, ses records, ses badges, et les mêmes chiffres traduits à hauteur d'enfant.

Essayer

Un voyage de démonstration est fourni

Pour voir le carnet plein plutôt que vide : Nancy → Venise, un mois de selle fabriqué de toutes pièces par un script. Toutes les captures de cette page en sortent.

$ git clone https://github.com/tmilefr/velo-journal.git $ cd velo-journal && npm install $ npm run demo # fabrique le carnet de démonstration $ npm start # http://localhost:3000

Chez vous

Vos étapes restent des fichiers, sur votre machine

Stockage

Un JSON et un dossier de photos

Aucune base à administrer, à migrer ou à sauvegarder de travers. Une archive ZIP complète se télécharge depuis le site, et se réinjecte de la même façon.

Accès

Deux mots de passe, trois rôles

Un pour publier, un pour la page famille, un troisième facultatif pour un enfant qui écrit ses propres étapes. Rien de public par défaut.

Défense

Les précautions d'usage

En-têtes Helmet, jeton CSRF sur chaque formulaire, échappement des saisies, cookie de session httpOnly et secure, connexion limitée à dix essais par quart d'heure.

Serveur

Node 20 et 200 Mo

Le plus petit VPS suffit. Nginx en façade, Let's Encrypt pour le certificat, PM2 pour le garder allumé — la marche à suivre complète est dans le dépôt.

Velo Journal est un projet personnel, publié tel quel. Le dépôt ne porte pas encore de fichier de licence : à ajouter avant de le diffuser largement.
